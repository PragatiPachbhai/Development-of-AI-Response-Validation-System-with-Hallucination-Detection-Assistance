# SQL Interview Questions and Answers

This repository contains SQL interview preparation notes with theoretical questions, answers, practical SQL queries, and common interview problems using MySQL 8.0.

## Topics Covered

- Database Fundamentals
- SQL Data Types
- SELECT, WHERE, DISTINCT, and ORDER BY
- Aggregate Functions
- GROUP BY and HAVING
- Joins: INNER JOIN, LEFT JOIN, and Self Join
- Subqueries and Correlated Subqueries
- Common SQL Interview Queries
- Common Table Expressions (CTEs)
- Window Functions: ROW_NUMBER(), RANK(), and DENSE_RANK()
- Constraints and Keys
- Indexes and Query Optimization
- Normalization: 1NF, 2NF, 3NF, and BCNF
- Transactions and ACID Properties
- Output-Based and Query-Writing Practice

## Repository Contents

- `SQL_Interview_QA.sql` — Contains SQL interview questions, answers, sample tables, sample data, and practical query examples.

## How to Use

1. Clone or download this repository.
2. Open `SQL_Interview_QA.sql` in MySQL Workbench or another compatible SQL editor.
3. Use a practice database and run the sample setup section first.
4. Read each question and answer, then execute the corresponding SQL query.
5. Practise writing queries independently before checking the solutions.

**Important:** The setup script drops tables named `employees` and `departments` before recreating them. Run it only in a practice database and ensure those tables do not contain important data.

## Requirements

- MySQL 8.0 or a compatible MySQL client.
- Basic understanding of relational databases and SQL syntax.

## Objective

The objective of this repository is to strengthen SQL fundamentals, practise interview-style queries, understand database concepts, and learn basic query optimization techniques.

## SQL Dialect

The examples are written for MySQL 8.0, including Common Table Expressions (CTEs) and window functions.
